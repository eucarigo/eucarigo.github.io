SAMP

2026 · Python · v1.3.0

SAMP (acrónimo en inglés de Spotify Ad Muter Panel, en español Panel para silenciar anuncios de Spotify) es una aplicación ligera para Windows que controla automáticamente el volumen de Spotify en función de si se está reproduciendo una canción o un anuncio.

Permite ajustar por separado el nivel de volumen para canciones y para anuncios (pudiendo silenciarlos por completo), además de integrarse de forma fluida con el volumen del sistema de Windows.

descargar instalador (v1.3.0) versión portable (.zip) código fuente

Características de la versión 1.3.0

  • 🎛️ Controles independientes: Deslizadores independientes para el volumen de canciones y anuncios.
  • 🔊 Volumen del sistema: Control directo del volumen maestro de Windows desde la propia ventana.
  • 🔄 Detección automática e inteligente: Análisis en tiempo real del estado de reproducción mediante la API GSMTC/SMTC de Windows.
  • ⚡ Ajuste instantáneo: Cambio inmediato del volumen de la sesión de audio de Spotify usando WASAPI (pycaw).
  • 🔁 Iniciar con Spotify (SWS): Script en segundo plano que vigila el inicio de Spotify para lanzar SAMP de forma limpia y sin necesidad de elevación continua de UAC.
  • 🔒 Instancia única (IPC): Evita la ejecución de procesos duplicados integrando QLocalServer para traer la ventana existente al frente.
  • 🌍 Soporte multilingüe: Interfaz disponible en español, inglés, alemán y francés con cambio al vuelo desde los ajustes.
  • 🎨 Temas visuales: Selector de temas en tiempo real (Oscuro, Claro y Forestal).
  • ⏱️ Frecuencia ajustable: Configuración del intervalo de comprobación en décimas de segundo.

Requisitos previos

  • Sistema operativo: Windows 10 / 11 (64 bits, build 17763 o superior).
  • CPU: 1 GHz o superior (arquitectura x86_64).
  • RAM: 512 MB mínimo, 1 GB recomendado.
  • Espacio libre: 65 MB mínimo (100 MB recomendado).
  • Spotify: aplicación de escritorio instalada y ejecutándose.
  • Python: no es necesario si utilizas el ejecutable o ejecutable portable, pero para desarrollo necesitas Python 3.8+ (3.12 recomendado).

Dependencias (sólo para ejecutar desde código)

pip install PyQt6 qasync winsdk pycaw psutil comtypes

Instalación y Uso

Puedes descargar la versión que mejor se adapte a tus necesidades mediante las siguientes opciones:

  • Instalador ejecutable (Recomendado): Descarga SAMP_Setup_1.3.0.exe para instalar la app con asistente gráfico, crear accesos directos e integrar el servicio de inicio automático.
  • Versión Portable: Descarga y descomprime SAMP_1.3.0_Portable.zip para ejecutar SAMP.exe sin instalar nada ni requerir permisos de administrador.

Una vez iniciada la aplicación:

  1. Inicia Spotify y reproduce contenido.
  2. Ajusta los deslizadores según tu preferencia:
    • Sistema: controla el volumen maestro del equipo.
    • Canción: nivel de volumen preferido para la música.
    • Anuncios: volumen aplicado durante las pausas publicitarias (se puede fijar en 0%).
  3. SAMP detecta el cambio de estado y conmuta automáticamente el volumen de la sesión de Spotify.

💡 NOTA: Si ajustas los deslizadores manualmente mientras se reproduce una canción o anuncio, SAMP guardará ese valor como tu nueva preferencia para ese estado. Puedes configurar el idioma, el tema gráfico o activar el inicio automático presionando Ctrl+, para acceder a los Ajustes.

¿Cómo funciona?

  • Consulta los controles de transporte multimedia mediante la API winsdk (GSMTC/SMTC) de Windows.
  • Aplica una heurística basada en la disponibilidad del botón "Siguiente" para diferenciar canciones de anuncios no omitibles.
  • Ajusta el nivel de la sesión de audio del proceso Spotify.exe en tiempo real mediante pycaw (WASAPI).
  • Utiliza una línea de tiempo asíncrona basada en qasync + asyncio para monitorizar el sistema y refrescar la interfaz gráfica.
  • Implementa comunicación IPC mediante QLocalServer para garantizar una única instancia activa.
